# Sync plan — FEAT-0087 Extension lifecycle and safe file operations

SpecMan sync was blocked by the intentionally uncommitted M39 base in this
read-only-git worktree. This plan records the phase-first implementation
contract before code changes.

## AC-1 — disabled scaffold

Add a validated scaffold creator that writes manifest.json and main.js only for
a new safe id, returns exists without overwriting, and leaves enablement to the
settings path.

Files: src/script-storage.ts, src/script-manifest.ts, src/script-storage.test.ts,
src/workbench.ts.

## AC-2 — path-safe operations

Add supported companion-file validation plus create/read/rename/delete operations
under the validated script directory; reject traversal, absolute, metadata, and
unsupported paths.

Files: src/script-manifest.ts, src/script-storage.ts, src/script-storage.test.ts.

## AC-3 — mtime guard

Guard every file save and rename against the caller's last-seen mtime, returning
conflict without writing stale data.

Files: src/script-storage.ts, src/script-storage.test.ts, src/workbench.ts.

## AC-4/AC-5/AC-6 — lifecycle and diagnostics

Wire create/rename/delete/reload diagnostics into the workbench and keep explicit
per-vault enablement separate from discovery and editing.

Files: src/workbench.ts, src/workbench-main.ts, src/main.ts,
src/extension-registry.ts, src/settings.ts, e2e/extensions.spec.ts.
