## AC-1 (added): Given a plain fetch of `api.html`, when an agent reads the response
  without executing JavaScript, then it finds a visible instruction identifying
  the static API hand-off and direct links to `api.md`, `api-contract.json`, and
  `brulion-extension.d.ts`.

Approach: Add a normal, non-script-dependent hand-off paragraph to the static
HTML shell with relative links that work under the GitHub Pages base path.

Files:
- `api.html` — visible agent instruction and raw-file links.
- `src/api-docs.test.ts` — static HTML link assertions.

## AC-2 (added): Given the build's static output, when `api.md`, `api-contract.json`, and
  `brulion-extension.d.ts` are fetched, then they exist at stable `/brulion/`
  URLs, contain the current human guide, parse as the current contract, and
  expose the current TypeScript declarations.

Approach: Commit the three public files at their stable names and make `npm run
build` copy the Authoring Kit sources into them first, so both a fresh checkout
and a generated `dist/` expose the same artifacts.

Files:
- `public/api.md`, `public/api-contract.json`, `public/brulion-extension.d.ts` — static output inputs.
- `package.json` — `prebuild` copy command.
- `e2e/api-static-docs.spec.ts` — built-preview HTTP and no-JS checks.

## AC-3 (added): Given the corresponding files in `extension-kit/`, when the static
  artifacts are checked, then their bytes are identical to the Authoring Kit
  sources; changing a source without regenerating the artifacts fails the
  verification rather than silently publishing stale documentation.

Approach: Compare all three committed public artifacts byte-for-byte with the
Authoring Kit raw imports in Vitest; the prebuild copy repairs them before a
release build, while the test catches drift in a source checkout.

Files:
- `src/api-docs.test.ts` — source/artifact parity assertions.
- `package.json` — deterministic source-to-public copy step.

## AC-4 (added): Given a browser with JavaScript disabled, when an agent opens the API

Approach: Use a real Chromium context with JavaScript disabled against the
production preview and assert the static links are visible while dynamic mounts
