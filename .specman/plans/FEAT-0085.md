# Sync plan — FEAT-0085 Separate-window extension workbench contract

SpecMan sync was blocked by the intentionally uncommitted M39 base in this
read-only-git worktree. This plan records the phase-first implementation
contract before code changes.

## AC-1/AC-2 — launch and independent attach

Add a workbench route/window entry that carries the effective workspace reference,
restores the matching persisted vault, requests permission only for that vault,
and reads scripts independently.

Files: src/workbench.ts, src/workbench-main.ts, workbench.html, src/main.ts,
src/vaults.ts.

## AC-3 — permission failure

Expose a clear reselect/permission action and preserve the requested workspace
reference when attachment fails; never fall back to a different vault.

Files: src/workbench.ts, src/workbench-main.ts, src/vaults.ts.

## AC-4/AC-5 — filesystem source of truth

Keep all workbench state local to the window and refresh from the filesystem on
open/focus/reload; do not add an IPC correctness dependency.

Files: src/workbench.ts, src/workbench-main.ts, e2e/extensions.spec.ts.
