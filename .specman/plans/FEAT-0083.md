# Sync plan — FEAT-0083 Extension host commands and capability API

SpecMan `sync` cannot run while the FEAT-0081/0082 worktree is uncommitted, so
this plan is recorded manually before implementation.

## AC-1/AC-2 — commands

Add an injected `ExtensionHost` around `ExtensionRpcPeer`. Register namespaced
commands with bounded local ids and labels, return a revoker, expose actions, and
route action invocation back over `commands.invoke`. Dispose removes only this
host's actions and handlers.

Files: `src/extension-host.ts`, `src/extension-host.test.ts`, `src/actions.ts`.

## AC-3 — editor

Expose text, selection, replacement, and focus through narrow callbacks. Every
request/response remains an `RpcValue`; no editor or DOM object is handed to the
peer.

Files: `src/extension-host.ts`, `src/extension-host.test.ts`.

## AC-4 — notes

Normalize all note paths with `normalizeNoteName` before invoking injected note
callbacks, and pass expected mtimes through to the existing note/controller layer.

Files: `src/extension-host.ts`, `src/extension-host.test.ts`.
