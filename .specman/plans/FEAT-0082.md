# Sync plan — FEAT-0082 Script storage, manifest validation, and JavaScript editor

SpecMan `sync` was blocked because FEAT-0081 spike artifacts are intentionally
uncommitted in this worktree. This plan records the same phase-first implementation
contract before code changes.

## AC-1/AC-3 — discovery

Add a vault-relative storage module that opens `.brulion/scripts` without creating
it during discovery. Iterate only immediate directories, parse each manifest in
isolation, report malformed entries alongside valid ones, and sort by id. Keep
`.brulion` out of the existing note-folder tree.

Files: `src/script-storage.ts`, `src/script-storage.test.ts`, `src/note.ts`,
`src/note.test.ts`.

## AC-2/AC-4 — manifest and read contract

Add pure manifest parsing with v1 schema/API checks, safe lowercase ids, relative
`.js` entry paths, semver, known permissions, and bounded source size. Read returns
manifest/source plus both mtimes and fails closed for invalid or missing paths.

Files: `src/script-manifest.ts`, `src/script-manifest.test.ts`,
`src/script-storage.ts`, `src/script-storage.test.ts`.

## AC-5/AC-6 — guarded writes and delete

Create scripts only after validating manifest/source. Write the entry with the
caller's expected mtime and return `conflict` without touching bytes when another
writer changed or created it. Delete only a validated id recursively; never accept
traversal or absolute paths.

Files: `src/script-storage.ts`, `src/script-storage.test.ts`.

## AC-7 — editor

Add direct `@codemirror/lang-javascript` dependency and a reusable CodeMirror
editor module. Use the existing `ProgrammaticLoad` annotation so programmatic loads
do not report changes; expose text access and a `Mod-s` save callback without any
filesystem or execution side effects.

Files: `src/script-editor.ts`, `src/script-editor.test.ts`, `package.json`,
`package-lock.json`.
