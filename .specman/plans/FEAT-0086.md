## AC-1 — compact extension selector and deterministic file list

Replace the selectable extension rows with one labelled `<select>`. Refresh
rebuilds its options while preserving a still-valid selection and renders only
the selected extension's supported files below it.

Files: `workbench.html`, `src/workbench-main.ts`, `src/styles.css`,
`src/workbench.test.ts`, `e2e/extensions.spec.ts`.

## AC-2/AC-3 — real tabs with path-owned drafts

Add an ordered set of open file paths scoped to the selected extension. Clicking
a file opens or activates its tab; clicking a tab activates it; closing a tab
removes only the view while drafts remain keyed by extension id and path. Closing
the active tab selects an adjacent open tab or clears the editor. Tests are
written first for the tab-strip contract and browser behavior.

Files: `workbench.html`, `src/workbench-main.ts`, `src/styles.css`,
`src/workbench.test.ts`, `e2e/extensions.spec.ts`.

## AC-4/AC-5 — refresh and attachment resilience

Filter stale tabs during filesystem refresh, preserve valid tabs and drafts, and
leave existing attachment failure behavior intact. Diagnostics must not destroy
other open tabs.

Files: `src/workbench-main.ts`, `src/workbench.test.ts`.

## AC-6 — honest static headings

Remove decorative chevrons from the always-expanded Extensions and Files labels
and remove CSS that reserves space for those false controls.

Files: `workbench.html`, `src/styles.css`, `src/workbench.test.ts`.
