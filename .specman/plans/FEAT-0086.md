## AC-2/AC-3 — active tab slots and sidebar replacement

Change the workbench's tab state from an array of opened paths to stable tab
slots whose path may be empty. A sidebar click first searches all slots for the
path and activates the match; otherwise it assigns the path to the active slot,
or creates the first slot when none exists. Keep only the ordinary click handler
so double-click has no second contract. Drafts and mtimes remain keyed by
extension id/path, never by slot position. Add browser assertions before changing
the state model.

Files: `src/workbench-main.ts`, `e2e/extensions.spec.ts`.

## AC-4 — explicit empty-tab action

Add a trailing `+` to the tab strip. It appends and activates one empty slot,
clears the editor, and shows an invitation to select a file. Closing a slot
selects an adjacent slot without deleting its path-keyed draft.

Files: `workbench.html`, `src/workbench-main.ts`, `src/styles.css`,
`src/workbench.test.ts`, `e2e/extensions.spec.ts`.
