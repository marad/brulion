## AC-6 (added): Given the preference is enabled and a genuinely opened note is nested
  below a collapsed folder, when the active-note announcement reaches the
  sidebar, then every ancestor folder is expanded and persisted, the note row
  receives focus, and the sidebar scrolls it toward the vertical center; the
  sidebar's own collapsed state remains unchanged.

Approach: On a genuine active-note change with the preference enabled, add
all folder ancestors to the existing per-vault expanded set and persist it,
then render the current tree so hidden ancestors become visible. Extend the
active-row helper to focus the visible row and call `scrollIntoView` with
`block: "center"`; leave the separate sidebar-collapsed guard intact.

Files:
- `src/main.ts` — reveal/persist active-note ancestors before the focused repaint.
- `src/ui.ts` — center the focused visible row after updating the roving tab stop.
- `src/ui.test.ts` — assert centered scrolling and no scroll for disabled/unchanged/hidden cases.
- `e2e/active-note-focus.spec.ts` — nested-folder navigation, partial-listing recovery,
  persisted expansion, centering, and Markdown preservation coverage.
- `e2e/subfolders.spec.ts` — update the existing tree contract to reflect ordinary
  persisted ancestor expansion after M44.

## AC-4 (modified): Given the editor or a dialog currently has focus, when a poller repaint
  announces the same active note, then DOM focus and sidebar scroll stay where
  they were; given the preference is disabled, an active-note change updates
  visual/ARIA state but does not move DOM focus or scroll; given the sidebar
  itself is collapsed, navigation does not force it open or focus a hidden row.

Change: The review requires sidebar scrolling to be treated as part of the
same genuine-navigation guard as DOM focus; a same-note repaint, disabled
preference, or collapsed sidebar must not move either one.

Approach: Keep all side effects behind the existing `activeChanged` and
`focusActiveNote` checks. Do not call the helper during initial attach or
background list updates, and keep the sidebar's own collapsed CSS state
independent from persisted folder expansion.

Files:
- `src/main.ts` — retain the genuine-navigation and sidebar guards.
- `src/ui.ts` — return without focus or scrolling when the row is not visible.
- `src/ui.test.ts` — cover outside-focus preservation and hidden-row no-op.
- `e2e/active-note-focus.spec.ts` — verify the sidebar itself stays collapsed.
