# Sync plan — FEAT-0084 Sandboxed extension runtime and local script workbench

SpecMan sync remains blocked by the intentionally uncommitted FEAT-0081–0083
spike work, so this plan records the implementation boundary manually.

## AC-1/AC-2 — runtime and lifecycle

Use an opaque-origin `allow-scripts` iframe, CSP `connect-src 'none'`, a transferred
nonce-bound MessagePort, and a blob-loaded ESM bootstrap. Keep runner failures
isolated in a vault-scoped registry.

Files: `src/extension-runner.ts`, `src/extension-registry.ts`.

## AC-3 — action integration

Merge runner actions into the existing command palette/action-bar registry and
dispose them on vault changes.

Files: `src/main.ts`, `src/extension-registry.ts`.

## AC-4/AC-5 — workbench

Add a modal listing discovered scripts, reuse the JavaScript CodeMirror editor, and
save/delete through the guarded script-storage API.

Files: `src/extension-manager.ts`, `index.html`, `src/styles.css`.
