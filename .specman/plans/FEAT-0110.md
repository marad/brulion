## AC-1 (added): Given a visible paragraph and a completed `**…**`, `__…__`, `*…*`,
  `_…_`, or `` `…` `` sequence followed by a space, when the boundary rule is
  applied, then the returned visible projection hides only the delimiters,
  leaves the terminating space ordinary, places the caret after that space, and
  serializes the marked span with its Markdown delimiters in one model operation.

Approach: Extend the existing loss-aware projection with pure inline boundary
classification and source-preserving conversion. A completed, non-empty marker
immediately followed by the explicit boundary is re-imported as the rich
projection plus an ordinary trailing space; incomplete, escaped, empty, URL, and
punctuation cases are returned unchanged.

`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-2 (added): Given incomplete, empty, escaped, intraword-underscore, URL-adjacent,
  punctuation-adjacent, or whitespace-only marker input, when the inline rule is
  evaluated, then it remains editable literal/opaque text and no mark is
  created or source bytes dropped.

Approach: Use delimiter-aware scanning that rejects unmatched, escaped,
intraword underscore, whitespace-only, and unsupported/block contexts without
consuming source. Add discriminating tests for each literal path.

Files:
`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-3 (added): Given nested marks and imported `__…__`, `_…_`, or backtick syntax, when
  the document is imported and edited, then nested mark metadata is preserved,
  imported delimiter spelling remains unchanged until that span is deliberately
  rewritten, and newly created marks use canonical `**`, `*`, or backticks.

Approach: Preserve imported delimiter choice in untouched ranges and serialize
new wrapping through canonical markers. Keep nested marks as ordered mark stacks
and reproject after explicit source replacement.

Files:
`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-4 (added): Given a non-empty visible selection or a caret in an existing mark, when
  the bold, italic, or code formatting operation is invoked, then it wraps the
  selection canonically or unwraps the matching imported span, preserves the
  selection direction/content, and returns one source-model operation without
  changing unrelated/unsupported source.

Approach: Add pure toggle operations over visible ranges. Non-empty selections
wrap with canonical markers, matching existing marks unwrap, and a caret creates
an empty canonical pair. Return one replacement/model result without touching
unrelated opaque spans.

Files:
`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-5 (added): Given a pending marker at EOF or before Enter, Tab, blur, or save, when the
  flush predicate is evaluated, then only a complete non-empty construct commits;
  incomplete, escaped, empty, URL, and punctuation cases remain literal and
  editable. Repeating the operation is idempotent and undo can restore the
  pre-conversion source/model state.

Approach: Expose a shared boundary predicate for space, Enter, Tab, EOF, blur,
and save callers. Conversion is idempotent after reprojection and all operations
remain pure so CodeMirror adapters can dispatch one history transaction later.

Files:
`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-6 (added): Given a heading/block prefix, fenced/special block, link target, or
  unsupported syntax, when inline rules are evaluated, then block/special syntax
  is not consumed as an inline mark and remains available for its dedicated
  source-editing path.

Approach: Gate inline parsing to ordinary paragraph content and preserve block
prefixes, fences, links, tables, frontmatter, Mermaid, HTML, and unsupported
syntax as opaque source regions. Do not modify controller or renderer modules.

Files:
`src/rich-markdown.ts`, `src/rich-markdown.test.ts`

## AC-7 (added): Given an empty or whitespace-only selection, when a formatting operation
  is invoked, then it returns no operation (or creates only a canonical empty
  pair for a caret) and never emits an empty marked span.

Approach: Return no operation for empty or whitespace-only selections; only a
collapsed caret may request an empty canonical pair. Assert no empty marked span
is emitted.
