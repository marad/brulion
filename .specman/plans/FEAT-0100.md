## AC-1 (added): Given a rendered note containing ATX headings from H1 through H6, when
  the editor paints them, then H1 is about `1.35em`, H2 about `1.15em`, and
  H3–H6 are body-sized (`1em`) with bold heading weight; no heading is rendered
  at the former oversized scale.

Approach: Change only the existing heading render theme values on
`cm-h1`–`cm-h6`; verify computed ratios against the body size in real Chromium.

Files:
- `src/markdown-render.ts` — compact heading size/weight CSS.
- `e2e/rendering.spec.ts` — discriminating computed-style coverage for all levels.

## AC-2 (added): Given the user's base text-size setting changes, when the same heading
  is rendered, then its computed pixel size scales with the body size while
  preserving the relative hierarchy.

Approach: Reuse the existing `--editor-font-size` setting application, then
measure the same heading before and after the Settings text-size control changes.
No new typography state or serialization is introduced.

Files:
- `e2e/rendering.spec.ts` — base-size scaling assertions using the Settings modal.

## AC-3 (added): Given light and dark editor themes, when headings are rendered, then the
  compact size/weight hierarchy remains the same and no custom heading color or
  indentation is introduced.

Approach: Exercise the existing theme radio controls in both explicit modes and
compare heading/body size ratios plus computed spacing/color inheritance; do not
add theme-specific heading selectors.

Files:
- `e2e/rendering.spec.ts` — light/dark regression checks.

## AC-4 (added): Given a note containing headings and inline bold text, when the editor
  renders or the user changes heading size/theme settings, then the original
  Markdown bytes remain unchanged and heading/inline decorations remain
  separate.

Approach: Save a mixed heading/bold fixture through the existing guarded editor
path after the visual checks and compare the exact OPFS bytes; assert heading
and strong spans remain separate DOM decorations.

Files:
- `e2e/rendering.spec.ts` — exact Markdown-byte and decoration assertions.
