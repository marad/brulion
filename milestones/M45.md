# M45 — Workflow enforcement and recovery

M45 makes the repository workflow executable instead of relying on prose alone.
It is development infrastructure; it must not change the application or the
user-owned markdown format.

## P3 — Workflow evidence and adaptive quality gates (FEAT-0107)

Make the existing gates select the actual milestone, catch plan/artifact drift
before review, and preserve review evidence outside chat.

**Done =** CI and local gates resolve the active milestone without a historical
hard-coded default, pre-review catches recursive plans and derived-artifact
drift without writing state, and the review protocol records a durable
base/HEAD/round/status/evidence trail while preserving the existing full tests
and fail-closed worker rules.

## Done =

A fresh trusted checkout can discover the workflow commands, fail before unsafe
mutation when preflight state is missing or owned by another writer, and reject
commits/pushes in CI when the spec, review, verification, or test gates are not
satisfied. Subagent liveness uses attention/checkpoint recovery rather than
hard timeouts by default. The workflow also resolves the current milestone and
leaves durable, discriminating review evidence.
